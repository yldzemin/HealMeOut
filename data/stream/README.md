# Telemetry stream files

| File | What |
|---|---|
| `sample_telemetry.csv` | 20 one-minute ticks of **simulated** wearable telemetry (heart rate, SpO2, temperature) for crew C1–C7. From minute 12, C5's SpO2 drops to 88% (a simulated event), so a replay shows the SpO2 rule firing. Generated by `astratwin.stream.SampleCsv` (seed 20261115). |
| `out/` | CSV logs of live streams, one file per run (`telemetry-<UTC time>.csv`). Not committed. |

Columns follow the `Reading` entity (`docs/TECH_OVERVIEW.md` §4.2):

```
timestamp,crewId,metric,value,unit,provenance,measuredHow
```

Any CSV with this header can be replayed: put it in this folder and call
`POST /api/stream/start?source=replay&file=<name>.csv`. Every distinct timestamp is one tick.

Regenerate the sample:

```sh
backend/api/build.sh && java -cp backend/api/out/classes astratwin.stream.SampleCsv data/stream/sample_telemetry.csv
```
